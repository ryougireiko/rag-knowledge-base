## 深入提问与参考思路

1. **为什么要 Chunk？** 答：控制上下文长度、提高匹配粒度，但过小会断语义，overlap 缓解边界割裂。可联系 `CHUNK_SIZE` 和 `CHUNK_OVERLAP`。
2. **VectorStore 和 Embedding 区别？** 前者持久化和 ANN/向量查询，后者把文本映射成向量。模型改版可能引起空间不兼容，需要重建索引。
3. **为什么不只用 BM25？** 精确术语和数字强，但同义表达弱；向量擅长语义匹配，混合检索互补。
4. **为什么 RRF？** 不同模型分数不可直接比较；按名次融合规避量纲差异。
5. **Rerank 为什么不是越多越好？** CrossEncoder 对候选对逐个打分，准确性可能提高但增加算力/延迟，应以评测取舍。
6. **如何避免来源被模型编造？** 后端构建 `[S#]` 来源映射，Prompt 限制；还需要引用校验/逐句核查，本项目暂未全面实现。
7. **Agent 与 Chain 的区别？** Agent 根据模型决策动态选工具，流程可能循环；固定 Chain 通常预先确定步骤。
8. **LangGraph 怎么记录状态？** Graph 使用 MessagesState；Sqlite checkpointer 按 `thread_id` 保存会话检查点，支持后续轮次继续。
9. **MCP 对比 Function Calling？** Function Calling 描述模型发起何种工具调用；MCP 规范模型应用与外部工具服务器的发现/参数与响应通信。本项目由 LangChain Tool 适配 MCP Client。
10. **为什么不能将未经信任的 RAG 文档当系统提示？** 文档可能带指令注入，检索结果是数据，不应赋予修改系统策略的权限。
11. **如何保证文档删除后检索不到？** 删除向量索引再删 SQLite 元数据；跨存储事务不原子，需要重建/补偿方案。
12. **为什么本项目不是企业级生产系统？** 未做租户隔离、SSO/RBAC、负载测试、灾备、完整审计与性能预算，范围是单机作品演示。
13. **SSE 是什么？** 服务端单向流式事件，适合 token 与检索来源更新；注意反向代理缓冲和连接中断。
14. **pytest 和 RAG Evaluation 有什么区别？** 单元测试验证功能按规则执行，RAG 评测关注证据召回及回答质量。
15. **Docker 解决什么问题？** 固化依赖和启动方式，但模型缓存、向量库持久化、Secret 管理仍需单独设计。
